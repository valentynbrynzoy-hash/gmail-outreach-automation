# 📬 Outreach блогеров — Google Apps Script

Система email-аутрича для работы с блогерами на Google Apps Script + Google Sheets. Закрывает полный цикл: холодное письмо → фолоу-апы в треде → детектирование ответов → обработка bounces — всё по местному времени блогера, с рандомизацией, чтобы письма не уходили пачкой в одну секунду.

---

## 📖 Часть 1 — Что это и зачем (простыми словами)

### Проблема

Рассылка холодных писем блогерам вручную — это: помнить кому когда писать, не забывать про фолоу-ап через пару дней, проверять не ответил ли кто, и не забыть, что письмо вернулось (bounce) и человеку больше писать не надо. На десятках строк это превращается в полноценную работу саму по себе.

### Решение

Заполняешь таблицу — имя блогера, его страна, email, дата отправки — и дальше всё происходит само:

- **Письмо уходит само**, в нужное время по часовому поясу блогера (а не посреди его ночи)
- **Фолоу-апы отправляются сами** — через 1, 5, 7 дней (настраивается), прямо в тот же тред с письмом, как будто ты сам зашёл и дописал
- **Если блогер ответил** — скрипт это видит и останавливает дальнейшие фолоу-апы по этой строке, чтобы не доставать человека повторно
- **Если письмо не дошло** (bounce) — строка помечается автоматически, видно сразу кому писать бесполезно
- **Времена рассылки рандомизируются** — письма не улетают всем одновременно секунда в секунду, что выглядело бы подозрительно

## ⚙️ Часть 2 — Техническая документация (для доработки)

### Скрипты

| Файл | Назначение |
|------|-----------|
| `Code.gs` | Основной скрипт — рассылка, фолоу-апы, проверка ответов, bounces. **Один экземпляр на каждую Gmail-почту** |
| `BatchFiller.gs` | Автозаполнение даты, аккаунта и времени отправки для новых строк блогеров. Запускается вручную через меню таблицы |

### Архитектура

```
Google Sheet (общая на все аккаунты)
├── 📋 Меню          — дашборд, список аккаунтов, настройки
├── 📮 Почты         — строки блогеров (одна строка = один блогер)
├── 📧 Шаблоны       — профили отправителей + шаблоны холодных писем
├── 🔁 Фолоу-апы     — шаблоны фолоу-апов (по номеру ФА и стилю)
└── 📊 Логи          — лог отправок / проверок / bounces
```

**Главное правило:** таблица одна общая, а вот `Code.gs` — отдельный проект на каждую почту. Если у тебя 3 Gmail-аккаунта рассылают письма — будет 3 отдельных Apps Script проекта (по одному на каждую почту), все смотрят в одну и ту же таблицу. Каждый проект отличается только одной строчкой — какой email указан в `MY_ACCOUNT`.

### Установка

#### 1. Таблица

Создай новую Google Таблицу или скопируй [готовый шаблон](https://docs.google.com/spreadsheets/d/16qKjhrJZzfqZ-qPVH3sqlcZZYcB5ilYC4bQ80HpGmqk/edit?usp=sharing) через **Файл → Создать копию**.

#### 2. Доступ к таблице для каждого аккаунта

Каждый Gmail-аккаунт, который будет рассылать письма, должен иметь доступ **на редактирование** к этой таблице (не просмотр!) — иначе скрипт не сможет писать статусы и логи.

→ Открой таблицу → **Настройки доступа** → добавь все остальные Gmail-адреса с правом **"Редактор"**.

#### 3. Apps Script проекты

**`BatchFiller.gs`** — добавляется один раз, через таблицу: **Расширения → Apps Script** → вставить код. Этот скрипт привязан к таблице и даёт меню **📬 Рассылка → 🚀 Заполнить новые каналы**.

**`Code.gs`** — отдельный standalone-проект **для каждой почты**:
1. Зайди на [script.google.com](https://script.google.com) **под тем Gmail-аккаунтом**, от имени которого должны отправляться письма
2. Создай новый проект, вставь `Code.gs`
3. Повтори для каждой следующей почты — отдельный вход в script.google.com под этим аккаунтом, отдельный новый проект

> Важно: проект должен быть открыт именно под нужным аккаунтом — иначе письма не будут отправляться от его имени.

#### 4. Авторизация (при первом запуске)

При первом запуске любой функции (`createTriggers`, `onOpen` и т.д.) Google покажет окно с предупреждением:

1. Нажми **"Дополнительные настройки"** (внизу слева)
2. Нажми **"Перейти на «название проекта» (небезопасно)"**
3. Разреши все запрошенные доступы (таблица + Gmail)

Это стандартное предупреждение для собственных скриптов, ничего опасного.

#### 5. Настрой верхний блок `Code.gs`

```javascript
const SPREADSHEET_ID = 'ID_ТВОЕЙ_ТАБЛИЦЫ';      // из URL таблицы
const MY_ACCOUNT     = 'твой_аккаунт@gmail.com'; // Gmail, от имени которого работает ЭТА копия

const ACCOUNT_ROW = {
  'твой_аккаунт@gmail.com':   6,   // номер строки в 📋 Меню для этого аккаунта
  'второй_аккаунт@gmail.com': 7,
  // добавляй по необходимости
};
```

`SPREADSHEET_ID` — длинная строка из URL таблицы:
```
https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit
```

#### 6. Включи Gmail API

В редакторе Apps Script: **Сервисы → Добавить** → включи **Gmail API** (нужен для отправки фолоу-апов в тред).

#### 7. Заполни таблицу

- **📧 Шаблоны** → строка профиля отправителя для `MY_ACCOUNT` (отметь активным `✅`)
- **📧 Шаблоны** → хотя бы один активный шаблон письма
- **🔁 Фолоу-апы** → шаблоны для ФА №1, №2, №3
- **📮 Почты** → строки блогеров: имя, гео, дата, местное время, email, аккаунт, стиль шаблона

#### 8. Параметры рассылки

В **📋 Меню**, строки 19–32:

| Ключ | По умолчанию | Описание |
|------|-------------|----------|
| `FOLLOWUP_ENABLED` | `TRUE` | Включить/выключить фолоу-апы |
| `FOLLOWUP_COUNT` | `3` | Максимум фолоу-апов на блогера |
| `FOLLOWUP_INTERVAL_1` | `1` | Дней после холодного письма до ФА1 |
| `FOLLOWUP_INTERVAL_2` | `5` | Дней после ФА1 до ФА2 |
| `FOLLOWUP_INTERVAL_3` | `7` | Дней после ФА2 до ФА3 |
| `CHECK_REPLIES_ENABLED` | `TRUE` | Включить проверку ответов |
| `CHECK_REPLIES_DAYS` | `30` | Сколько дней назад проверять |
| `CHECK_BATCH_SIZE` | `150` | Строк за один запуск проверки |
| `DAYS_UNIQUE` | `5` | Дней до повторного использования холодного шаблона |
| `DAYS_UNIQUE_FOLLOWUP` | `5` | Дней до повторного использования шаблона ФА |
| `BOUNCE_CHECK_ENABLED` | `TRUE` | Включить bounce-детектор |
| `LOG_RETENTION_DAYS` | `30` | Сколько дней хранить лог |
| `FOLLOWUP_STOP_ON_REPLY` | `TRUE` | Остановить цепочку ФА при получении ответа |

#### 9. Создай триггеры

В редакторе Apps Script: **Запустить → `createTriggers`** (один раз для каждого проекта/почты).

| Функция | Расписание |
|---------|-----------|
| `sendScheduledEmails` | Каждую минуту |
| `sendFollowUps` | Каждую минуту |
| `checkReplies` | Каждые 3 часа |
| `checkBounces` | Каждые 6 часов |
| `updateTriggerStatus` | Каждые 5 минут |
| `cleanLog` | Воскресенье в 3:00 |

### Переменные шаблонов

| Переменная | Подставляется |
|-----------|---------------|
| `{{блогер}}` | Имя блогера (колонка A листа 📮 Почты) |
| `{{имя_отправителя}}` | Имя отправителя |
| `{{подпись}}` | Блок подписи отправителя |
| `{{ватсап}}` | Строка WhatsApp отправителя |
| `{{тема_оригинала}}` | Тема холодного письма (только для ФА) |

### Режимы строк

| Режим | Поведение |
|-------|-----------|
| `полный` | Отправка + фолоу-апы + проверка ответов |
| `только проверка` | Без отправки, только проверка ответов |
| *(пусто)* | Устанавливается в `полный` автоматически после первой отправки |

### Статусы фолоу-апов

| Статус | Значение |
|--------|----------|
| `ожидание` | ФА запланирован, ждёт времени отправки |
| `ответил` | Получен ответ, цепочка остановлена |
| `завершён` | Все ФА отправлены |
| `нет треда` | Оригинальный тред не найден в Отправленных |
| `bounce` | Письмо вернулось, остановлено |

### Служебные функции

| Функция | Что делает |
|---------|-----------|
| `createTriggers()` | Создаёт все триггеры (один раз при настройке) |
| `deleteTriggers()` | Удаляет все триггеры |
| `resetStatus()` | Сбрасывает статус отправки по всем строкам |
| `cleanLog()` | Запускает очистку лога вручную |

### Поддерживаемые ГЕО

Скрипт конвертирует местное время отправки в UTC по захардкоженным смещениям:

`ПЕРУ` (-5), `ЧИЛИ` (-3), `АРГЕНТИНА` (-3), `КОЛУМБИЯ` (-5), `МЕКСИКА` (-6), `БРАЗИЛИЯ` (-3), `УКРАИНА` (+3), `ТАИЛАНД` (+7), `МОНГОЛИЯ` (+8), `ПАКИСТАН` (+5), `ШРИ-ЛАНКА` (+5)

Чтобы добавить новые страны — расширь объект `GEO_OFFSETS` в начале `Code.gs`.

### BatchFiller — автозаполнение новых строк

После добавления `BatchFiller.gs` в таблице появляется меню **📬 Рассылка → 🚀 Заполнить новые каналы**.

**Что делает:**
- Находит строки в 📮 Почты, где есть имя и гео, но не заполнены аккаунт и дата
- Распределяет их по активным аккаунтам равномерно (до `BF_MAX_PER_ACC` на аккаунт в день)
- Проставляет дату отправки, аккаунт и местное время с шагом `BF_INTERVAL_MIN` минут начиная с `BF_START_TIME`
- Умеет пропускать выходные

**Настройки** (верхний блок `BatchFiller.gs`):

| Константа | По умолчанию | Описание |
|-----------|-------------|----------|
| `BF_INTERVAL_MIN` | `5` | Минут между письмами одного аккаунта |
| `BF_START_TIME` | `09:00` | Время старта (украинское) |
| `BF_MAX_PER_ACC` | `10` | Максимум писем на аккаунт в день |

### Технические нюансы

- Не коммить в публичный репозиторий реальный `SPREADSHEET_ID` и Gmail-адреса — используй плейсхолдеры
- Суточные лимиты Gmail API применяются; скрипт ограничивает себя до 200 поисковых вызовов за запуск через `GMAIL_CALL_LIMIT`
- Каждый аккаунт обрабатывает только строки, где колонка F (`С какого аккаунта`) совпадает с его `MY_ACCOUNT`
